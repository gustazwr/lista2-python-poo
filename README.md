# Lista de Exercícios II - Programação Orientada a Objetos

Repositório contendo as implementações das questões utilizando:

* Herança
* Polimorfismo
* Classes Abstratas (ABC)
* Protocol

## Estrutura do Projeto

* sistema_midias_educacionais
* sistema_Funcionarios_empresa
* sistema_notificacao_abc
* sistema_impressao_protocol
* sistema_armazenamento_abc_protcol

---

# Como executar os projetos

## 1. Clonar o repositório

```bash
git clone https://github.com/gustazwr/lista2-python-poo.git
```

---

## 2. Entrar na pasta do projeto

```bash
cd lista2-python-poo
```

---

## 3. Executar uma questão

### Exemplo — Sistema de Mídias

```bash
cd sistema_midias_educacionais
python main.py
```

---

### Exemplo — Sistema de Funcionários

```bash
cd sistema_Funcionarios_empresa
python main.py
```

---

### Exemplo — Sistema de Notificações

```bash
cd sistema_notificacao_abc
python main.py
```

---
